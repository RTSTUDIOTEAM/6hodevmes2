# 6-H Sınıf Panosu & Titreşimli Sohbet (Port 610)

Orijinal sesli, 24 saatlik sunucu depolamalı, otomatik silmeli ve küfür filtreli okul sohbet uygulaması.

## Kurulum ve Çalıştırma

1. ZIP dosyasını çıkartın.
2. Terminal açıp bağımlılıkları yükleyin:
   ```bash
   npm install
   ```
3. Sunucuyu başlatın:
   ```bash
   npm start
   ```
4. Tarayıcınızdan açın:
   ```text
   http://localhost:610
   ```
