# 6-H Sınıf Panosu & Titreşimli Sohbet (Port 610) v6.3

Orijinal sesli, 24 saatlik sunucu depolamalı, otomatik silmeli ve küfür filtreli okul sohbet uygulaması.

Özellikler:
- PDF / tüm ses formatları / video / diğer dosya desteği
- Boyut limitleri: PDF 15MB, Video 10MB, Ses 7MB
- Girişte ad sorma (hatırlanır, değiştirilebilir)
- Yeni mesaj sesi
- Online kişi sayısı
- Yazıyor... göstergesi
- Mesaj ⓘ menüsü: Kopyala / Düzenle / Sil
- Tıklanabilir mavi altı çizili linkler
- Mobil uyumlu alt çubuk

## Kurulum
1. ZIP çıkart
2. npm install
3. npm start
4. http://localhost:610
